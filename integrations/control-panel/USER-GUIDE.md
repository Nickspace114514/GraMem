# GraMem 日常操作指南

打开 [GraMem 控制台](http://<宿主地址>:8500/control)，使用现有管理员账号登录。先确认顶部的“工作空间”和“记忆身份”：账号关联属于整个工作空间，画像、记忆与导入则作用于当前选中的记忆身份。

## 关联同一个人的账号

1. 打开“账号与身份”，查看“已关联账号”。
2. 在“添加账号关联”选择平台，填写该平台的真实账号标识。Telegram 使用数字用户 ID，你的 ID 是你自己的数字用户 ID（示例 `1000000001`）；不要填写 `@你的用户名`。邮件填完整邮箱；Slack 填成员 ID；Teams 填 Entra 对象 ID。
3. “共用身份”选择“我（你的身份）”，或已有联系人。为新联系人选择“另一位联系人（新身份）”，输入稳定标识，例如 `friend-alex`。
4. 核实账号归属后勾选确认，点击“加入关联列表”，再点击“保存身份设置”。列表里的“编辑”“解除关联”也要保存后才会生效。
5. 保存会校验并备份。重启宿主服务后，后续消息使用新的身份识别结果。

你目前的 Telegram 账号已经关联到“你的身份标识”，和已关联的邮件、Slack、Teams 账号共用身份。新增关联不会自动把此前独立联系人的旧记忆搬过来。账号关联也不会修改 Telegram 的允许访问名单；这是两个独立设置。

“我的身份”标识用于定位已有记忆，不能当成昵称随意修改；更换需要迁移。群聊保持独立的群组记忆空间。

## 修改画像与偏好

- 打开“画像与偏好”，按中文分类查看结论。点击“查看来源”，编辑“事实内容”，再点击“保存来源修改”。实际修改的是来源记忆，历史版本会保留，画像随有效来源更新。
- 添加新偏好，在“希望记住的事实”写普通文字，例如“我喜欢先给结论，再解释原因”，选择“偏好”，点击“保存这条事实”。身份特征、兴趣等也用同样的方法。
- 暂时不希望使用某条来源，可在来源区域选择停用。停用按整个主题槽位生效；解除停用与重新授权入口在排除记录区域。
- “重新归纳画像”会调用配置的模型，可能产生费用。普通新增、来源修改不需要重启服务；候选事实是否立即有效仍取决于审核设置。

## 调整记忆行为和事实关系

“行为与模型”的每日衰减率使用数字输入：值越大，记忆淡化越快；`0` 表示不衰减。需要确认的事实类型使用勾选项。修改后点击“保存行为设置”，再重启宿主服务。

在“记忆”中新增或编辑事实，展开“有事实来源的关系”，按“主体 / 关系 / 对象”填写，例如“我 / 偏好 / 简洁回答”。不需要写 JSON，也可以不填关系。

## 管理 GraMem 模型

打开“行为与模型”中的“GraMem 模型管理”。Chat 用于记忆提取、语义排除判断和画像归纳；Embedding 用于向量召回。可以选择推荐模型，也可以输入阿里官方模型 ID；留空会停用对应模型能力。

当前使用 `qwen3.8-flash` 和 `text-embedding-v4`（1024 维）。连接固定为阿里 DashScope 官方接口，密钥在下方独立凭据表单中管理。修改模型、向量维度、空间版本或请求超时后，点击“保存模型配置”，再重启宿主服务。

更换向量模型或维度时，页面会自动更新空间版本，避免混用不同模型的向量。知识库 worker 会逐步重建知识库向量；普通记忆旧向量不保证自动重建，关键词和图召回仍可使用。

## 导入已有记忆

在“导入与维护”上传 JSON 或 JSONL 文件，先在预览里检查和编辑内容、类别、主题以及排除记录，再点击“执行导入”。预览只显示前 100 条记忆和排除记录，导入会处理整个文件，最多各 10000 条。原记录的其他信息会保留。

也可以用“添加记忆”直接填写几条事实。已审核记录的直接激活需要单独勾选确认；默认沿用原生审核。原始 JSON 入口折叠在“高级”中，普通操作不需要使用。

## 什么时候需要重启

账号身份、行为参数、模型和连接凭据：保存后需要重启。事实、画像来源编辑与导入：不用重启。

当前服务器使用 systemd 用户服务。等正在进行的回复结束后，在服务器终端执行：

```sh
systemctl --user restart hermes-gateway.service gramem-knowledge-worker.service hermes-control.service
systemctl --user is-active hermes-gateway.service gramem-knowledge-worker.service hermes-control.service
```

三个服务都应显示 `active`。页面保存遇到“配置已被其他操作修改”，先记录自己的改动，刷新后再修改；冲突检查用于防止覆盖别处刚保存的设置。
