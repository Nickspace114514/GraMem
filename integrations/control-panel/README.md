# GraMem 记忆控制台

面板 2.0.0，配合 GraMem 2.5.0 / schema 8 的附属管理组件，通过 Hermes 现有 dashboard 插件机制提供 UI 与管理员接口，不修改 Hermes 核心代码、不注册模型工具。

2.0.0：界面完全重做为“记忆档案馆”风格：左侧分组导航、衬线标题、以记忆强度条为核心的条目列表、侧滑详情抽屉、自定义确认对话框与自动消失的提示。接口不变，新增/完善：候选记忆“通过”操作；记忆每页条数与总页数、本页全选和勾选操作栏；语义召回显示召回条目；总览显示状态分布、模型可用性、自动审核、累计 Token、身份切换与最近任务；知识库拖拽上传、逐个文件进度（单个失败不中断其余）、单文件标题、连续阅读；聊天平台/主题/会话快速筛选与清除；记忆网和关系图支持拖动、平移、按钮与滚轮缩放（不再带动页面滚动）、节点类型筛选和点击连线查看来源；持久队列以表格展示；设置分组导航、修改标记和吸附保存栏；更换向量模型前提示。外观仍保存在浏览器本地。1.8.1 静态资源备份在私有 deploy 目录。

1.8.1：增加 GraMem 独立模型管理，Chat/Embedding 推荐与自定义官方模型 ID、向量维度、空间版本、超时；固定使用阿里 DashScope 官方接口和 DASHSCOPE_API_KEY。保存带备份、revision 冲突检查和未保存修改提醒；更换向量模型或维度会自动更新空间版本。

1.8.0：账号关联使用平台/账号/共用身份表单；画像按中文分类显示并支持编辑来源事实；衰减、确认类型、事实关系使用表单；迁移支持文件预览编辑，详情与队列优先结构化显示。高级 JSON 仅作为可选入口。普通操作参见[日常操作指南](USER-GUIDE.md)。身份保存校验数字 Telegram ID、邮箱归一及重复账号，保留原有 revision/备份/profile 边界。

1.7.0：聊天详情新增关联助手语音、原件播放/下载及聊天与语音原件包，列表提示语音数量；记忆网增加音频节点。所有读取沿用身份/profile、禁提和原生撤销校验。

最终范围：只管理 GraMem。Hermes 主模型、供应商、自动压缩、Cron、渠道、工具、插件、会话、SOUL.md 等继续使用官方面板；本组件没有这些管理入口或 API。

核对日期：2026-10-08，Asia/Singapore。完整参数、分页和错误码见[REST 接口手册](../../docs/control-panel.md)，数据边界见[架构](../../ARCHITECTURE.md)，升级/回退见[部署](../../docs/deployment.md)。

## 界面

记忆档案馆风格：左侧分组导航（工作空间与记忆身份在侧栏顶部），衬线标题，安静的纸面色调；明亮／深色／跟随系统，五种主题色与自定义颜色，设置保存在浏览器本地。主题只作用于 GraMem 工作台，离开页面恢复官方面板外壳。

- 总览：当前 profile 各状态记忆与图同步队列计数。
- 记忆：中文全文搜索与完整分页、语义召回、状态过滤、来源/版本详情、新增、更新、合并、自动审核进度、拒绝、停用、遗忘。显式事实支持有来源的 subject/predicate/object 关系。
- 知识库：多文件/图片上传与说明、去重/版本、后台解析、中文搜索、分块阅读、原件下载、重试、停用和遗忘。
- 关系图：网状力布局，搜索实体，1–3 跳、历史关系、方向箭头、历史虚线、节点拖动、平移、缩放、局部高亮和来源查看。继承 GraMem 的路径来源及排除校验。
- 聊天档案：跨平台/session/日期查询、主题时间线、原话和原件下载；当前身份一键处理全部历史、持续进度与失败重试。
- 记忆网：事实、文件、聊天、摘要、主题、实体、会话和事件；沿可见节点展开，权重、衰减、状态和时间连接。
- 画像与偏好：来源约束的画像、即时反思、排除记录、解除停用与明确重新授权。可直接查看并编辑来源事实，或用普通文字补充新偏好；修改保留历史版本，画像按有效来源更新。
- 账号与身份：查看已关联账号、添加/编辑/解除关联、选择共用身份和调整本机/群聊信任，无需手工编辑 aliases JSON。稳定 owner 标识只读，修改需单独迁移。
- 行为与模型：召回预算、阈值、衰减、确认类型、阿里官方 Chat/Embedding 模型及 FalkorDB 连接。Owner 和账号绑定在“账号与身份”管理。密钥只写入宿主保密存储，不返回原值。
- 导入与维护：上传 JSON/JSONL、可编辑预览及排除记录迁移、生命周期维护、同槽整理与画像、单次任务处理、图同步、含 SQLite/原件/校验清单的知识 ZIP 备份、队列查看。

GraMem 当前版本的提取、语义排除分类与画像共享一个 Chat 模型；Embedding 使用独立模型名、相同 API 地址和凭据。页面忠实反映现有引擎能力。

## 部署

复制本目录到所选宿主默认 home 的 `plugins/hermes-control`，执行 `hermes plugins enable hermes-control` 并重启 dashboard。入口为 `/control`。服务端使用原生 dashboard 认证与 profile/secret scope，无第二套认证。

部署实例的入口为 `http://<宿主地址>:8500/control`，宿主中以用户服务 `hermes-control.service` 运行；`hermes-gateway.service` 独立运行。安装时端口统一为 8500；保留已配置的认证账号，首次安装才创建凭据。通用部署请使用 Hermes 官方方式。新登录凭据写入 root home 的 mode-600 文件，不包含在本组件源码中。

代码作为 GraMem 附属组件同时保存于项目 `integrations/control-panel/`。

## 安全与生效边界

每个 API 由 Hermes 认证中间件保护，并在明确选定的 profile 下执行。只有实例管理员访问本面板，不能将全 profile 总览提供给外部联系人。顶部的记忆身份选项仅来自当前库已有 principal；数据查询不接受新造的任意用户身份。管理员可以在账号关联表单中创建联系人稳定标识，该操作仅更改后续身份识别。

搜索分页没有 Engine.list 的 200 条上限。图服务原有单次最多 200 条，因此页面单次显示最多 199 条，多取一条检测截断；达到上限时提示搜索更具体的实体。图健康独立检测，避免把连接错误解释为无关系。

设置保存校验类型与引擎约束，自动备份，检测 revision 冲突。配置与凭据更改需要重新启动 Gateway、dashboard 和独立知识 worker。改变 Owner、图 namespace、home 或 embedding 空间需要规划迁移，不自动搬运历史数据。

遗忘和停用均对整个语义槽位生效；使用 GraMem 原生事务、排除与持久图队列。重新授权只允许新事实，不恢复被遗忘的旧值。遗忘不等于擦除宿主历史、日志和旧系统数据。

知识 ZIP 包含 SQLite 和原件，不包含独立 FalkorDB；页面明确提示图需另行备份。后台统计是数据库持久队列；管理请求的模型调用计数不是宿主累计账单。

## 验证

`tests/verify.py` 通过真实 GraMem 引擎和临时 A/B homes 验证超过 200 条的中文搜索分页、版本更新/合并、确认/拒绝、排除与重新授权、profile 隔离、配置校验与冲突、迁移、文档导入及一致性备份；独立临时 graph namespace 验证真实 FalkorDB 的来源、历史版本及排除。

部署实例的只读验证（脚本随私有部署材料维护）覆盖：未登录 401、原生密码登录、所有 GraMem 查询、原件下载 hash/文件名/未登录拒绝、图健康、密钥不返回原值、未知 profile 拒绝及已移除的 Hermes 人格接口 404。

浏览器验收覆盖 Material 3 Expressive 明暗切换、主题色、GraMem 独立导航、行为/模型字段和图显示器。生产记忆没有添加测试事实。

## 历史版本变化

下列版本记录保留各阶段新增能力；当前版本及完整接口以页首和 REST 手册为准。

### 1.4.0

新增聊天档案与统一知识网络页面：跨平台和会话查询、时间范围、摘要时间线、原话及原件下载；交互图包含聊天、摘要、文件、事实、主题、实体和会话，支持沿选中节点继续展开。后台 API 与原有认证和 profile 隔离共用。

### 1.5.0

页面统一命名为记忆网，增加记忆事件与时间顺序连接；节点大小按强度、置信度或重要性显示，详情与记忆本体同步并区分历史及待审核状态。原始记录无关联记忆时标记未评估，禁提内容不能通过历史事件或权重聚合恢复。

### 1.6.0

聊天档案增加“一键处理全部未整理记录”：后台分页补齐当前身份在启动前的可信私人历史，整理未完成记录，显示进度及失败重试。重复点击复用任务，关闭页面或重启后继续，已完成记录跳过；保留原件、主题及记忆网连接，沿用持续禁提策略。任务覆盖整个选定身份，页面筛选不会限制范围。需要运行现有知识 worker/provider 或 CLI worker。

### 1.6.1

记忆分页将聊天来源状态、策略 epoch 和原生撤销状态纳入 blocked 集合，并递归隐藏派生结论；分页总数与内容使用相同过滤。配合 GraMem 2.4.1/schema 7。

2026-10-04 已部署并完成认证查询、分页来源过滤、原件 hash 和图健康验收；部署记录未随仓库发布。
