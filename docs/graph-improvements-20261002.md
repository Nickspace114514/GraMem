# 关系图查询与自动召回优化（2026-10-02）

本轮继续优化本地 GraMem 源码，未部署生产服务，也未读取或改动生产事实。

## 行为变化

- 从主体或对象两端均可进入图查询。例如搜索 FalkorDB 能找到使用它的项目，返回仍保持“项目 → USES → FalkorDB”的原方向。
- 多跳先检查整条来源路径，再按关系 ID 去重，采用候选中的最短有效路径。一条路径被停用时，其他有效的绕行路径仍可使用。
- 空搜索直接查询全部实体的一跳关系，避免无意义的多跳重复展开。图层过滤跨身份与已失效边，引擎再次以 SQLite 的生命周期和排除状态核对路径；同次查询复用来源校验结果。
- 普通召回默认从问句中提及的实体名称展开两跳，补充原本没有全文/向量相关度的来源事实，并附上有证据的关系三元组。图连接本身不产生新的推断事实。
- 图补充、全文、向量按事实 ID 去重后统一评分。图补充默认最多 3 条、256 tokens，包含在原有 1024 token 总预算中；未交付不强化、历史不强化、同轮重试不重复强化。即使事实已进入向量或历史候选窗口，相关度仅由图提供时仍计入图子预算。
- 图网络查询在 SQLite 事务之外执行，最终交付事务内再次校验路径，防止查询期间发生的停用/遗忘被旧结果绕过。
- 图请求失败后，普通召回继续工作，同一引擎的自动图请求暂停 30 秒；显式图工具仍可立即重试。

## 配置与接口

新增 graph_recall_enabled=true、graph_recall_hops=2、graph_recall_limit=3、graph_recall_tokens=256。管理面板提供中文字段；完整参数见 [配置手册](configuration.md)。已有配置无需迁移，缺失键采用默认值；关闭 graph_recall_enabled 可恢复仅全文/向量召回。

图返回新增 distance，表示实际采用的来源路径跳数。Python Engine.graph / FalkorGraph.search 新增 match_text=false，自动召回传 true，按问句出现的完整实体名匹配；显式图搜索保持名称子串搜索。

实体依然使用原名，不自动把名称相似的实体合并。每次读取最多 800 条路径候选、对外最多 200 条关系；密集图仍可能遗漏超过候选上限的路径，不承诺全图穷举。

## 验证

132 项测试通过，其中 4 项使用与项目部署相同版本和镜像摘要的真实 FalkorDB，覆盖入边、原方向、自然问句、空查询、多跳去重、有效绕行、身份隔离、历史更新、遗忘和自动两跳召回。

其余新增测试覆盖跨身份/异常图结果、图子预算、向量/历史候选的图相关度、同轮强化、交付前并发停用、图不可用的退避、关闭自动图召回及配置范围。Python 全量 ruff 与面板 JavaScript 语法检查通过。

真实验证在独立临时容器环境和随机图 namespace 中运行；每个用例删除自己的 namespace，验证结束移除整个临时环境。未调用远程提取或 embedding 模型。

查询函数与路径语法核对了 [FalkorDB 官方函数文档](https://falkordb.github.io/docs-staging/cypher/functions/)，并由上述真实数据库用例验证。
