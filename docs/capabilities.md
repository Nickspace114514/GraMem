原始系统的平台适配、邮件网关、提醒、人格编辑与宿主模型运维等冗余功能已移除；现有附属控制台只管理 GraMem；这些职责交给 Hermes。图仍是独立服务，事实与任务不再需要 PostgreSQL/Redis 两套存储。

向量检索目前是按 scope 过滤后的线性扫描，适合个人规模，不承诺百万级 ANN 性能。API embedding 会将查询与事实文本发送给已配置服务商。语义提取和忘记识别依赖模型，验证通过不代表零漏判。

长用户证据按输入预算拆分成持久任务，逐块提取，跨块语义仍可能丢失；大文档请显式 ingest。图关系由提取模型生成，显式 CLI remember/ingest 默认不调用图提取；Python 可传有来源的 relations。知识库现支持本地图片与扫描 PDF OCR（需 Tesseract、语言包和 Poppler），保留原件并记录页码/分块来源；助手语音按可信关联长期保存原件，合成文案不是 ASR 转写；通用音视频解析和网页抓取仍由 Hermes 负责。见 [知识库](knowledge-base.md)。

“遗忘”覆盖插件管理的当前记录，不承诺擦除 Hermes 历史、旧 Hindsight 卷、文件系统历史页、日志或当前模型上下文。旧记忆后端停用不等于旧磁盘数据已物理删除。完整范围与返回字段见接口手册。
